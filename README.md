# Credit Card Fraud Detection

## Project Overview
This project builds a machine learning model to detect fraudulent credit card transactions.

Fraud detection is an important real-world application in banking and financial institutions.

## Technologies Used

Python  
Pandas  
NumPy  
Matplotlib  
Seaborn  
Scikit-learn  

## Machine Learning Model

Logistic Regression

## Steps in Project

1. Data loading
2. Data preprocessing
3. Feature scaling
4. Train-test split
5. Model training
6. Model evaluation

## Evaluation Metrics

Accuracy  
Confusion Matrix  
Precision  
Recall  
F1 Score
